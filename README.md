# 2026-9 SSE 离子电导率测量

## 操作描述

### 1. SSE 样本制备

操作方式与半电池中的 SSE 压制步骤一致，分别制备两类样本：

- 标准硫化物电解质样本；
- 混合了预设材料的混合硫化物电解质样本。

本次测量不放入正极材料或负极材料。

### 2. 电阻测量

使用电化学工作站，按照标准程序分别测量两类样本的电阻。

### 3. 模具拆卸与 SSE 厚度测量

按照模具电池的拆解操作取出 SSE，使用厚度测量仪测量 SSE 厚度。SSE 饼周边可能有翘起结构，测量前应清理，避免影响结果。同一样本测量 3 次，取平均值作为该样本的厚度。

## 测量原理

电化学工作站测得样本的离子传导电阻后，可结合样本的几何尺寸换算离子电导率：

$$
\sigma_{\mathrm{ion}} = \frac{L}{R_{\mathrm{ion}} A}
$$

其中，L 为按第 3 步测得的样本平均厚度，A 为垂直于离子传导方向的截面积，R_ion 为测得并归属于样本离子传导的电阻。若长度使用 cm、面积使用 cm²、电阻使用 Ω，则离子电导率的单位为 S/cm。

因此，电阻值需结合样本厚度和截面积解释。比较标准硫化物电解质与混合硫化物电解质时，应使用各样本对应的尺寸进行换算；换算结果表征该样本整体的有效离子电导率。
