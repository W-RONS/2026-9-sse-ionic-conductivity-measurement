# 2026-9 SSE 离子电导率测量

## 操作描述

### 1. SSE 样本制备

操作方式与半电池中的 SSE 压制步骤一致，分别制备两类样本：

- 标准硫化物电解质样本；
- 混合了预设材料的混合硫化物电解质样本。

本次测量不放入正极材料或负极材料。

### 2. 电阻测量

使用电化学工作站，按照标准程序分别测量两类样本的电阻。
